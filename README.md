## Что тут

5 лабораторных работ по предмету. Каждая в своей папке. Внутри папки — код и readme с описанием.

| № | Тема | Файл |

## Как запускать

Заходим в папку нужной лабы и запускаем:

    cd lab1
    python lab1.py

Аналогично для остальных.

## Что нужно

Python 3.10 или новее. Никаких сторонних библиотек не подключал, только стандартные модули: time, random, tracemalloc, base64, datetime, collections.
