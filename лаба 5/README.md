# Лабораторная работа 5. Обход бинарного дерева

## Задание

Дано произвольное бинарное дерево (не обязательно дерево поиска). Реализовать обходы и вычислить свойства.

Обязательная часть: pryamoy_obhod, simmetrichny_obhod, obratny_obhod, po_urovnyam (BFS), несколько тестовых деревьев.

Вариативная часть (6): найти самый длинный путь от корня до листа и вернуть список значений.

## реализация

Класс TreeNode хранит значкние и ссылки на левого и правого потомка.

Обходы в глубину (DFS) сделаны рекурсивно. Разница только в том, куда поставить result.append(root.value):
- pryamoy_obhod — сначала узел, потом левое, потом правое
- simmetrichny_obhod — левое, узел, правое
- obratny_obhod — левое, правое, узел

Обход в ширину (po_urovnyam) через очередь deque. Кладём корень, потом вынимаем его и добавляем его детей в конец. Так узлы обрабатываются уровень за уровнем.

## Вариативная часть

samy_dlinny_put работает рекурсивно. Если узел лист (нет ни левого ни правого) — путь заканчивается, возвращаем список из одного значения. Иначе рекурсивно спрашиваем путь в левом и правом поддеревьях, берём тот что длиннее, и приписываем текущий узел в начало.

## сложности

| операция | Время | память |
|----------|-------|--------|
| DFS-обходы | O(n) | O(h) —глубина рекурсии |
| BFS | O(n) | O(w) — ширина уровня |
| samy_dlinny_put | O(n) | O(h) |

где n — количество узлов, h — высота, w — максимальная ширина уровня.

## Тестовые деревья

1. Обычное дерево из 6 узлов.
2. Ёлочка из 5 узлов.
3. Бамбук (все узлы только влево) — проверяет что рекурсия не ломается на глубине.

## Граничные случаи

- root = None — все функции возвращают пустой список.
- один узел — обходы возвращают [value], путь тоже [value].
