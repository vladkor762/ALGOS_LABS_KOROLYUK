# Лабораторная работа 3. Очередь через два стека

## задание

Реализовать очередь (FIFO), используя два стека (LIFO).

Обязательная часть: dobavit(x), dostat(), front().

Вариативная часть (6): метод soderzhit(x) — проверяет есть ли элемент в очереди.

## Идея

Очередь и стек работают в противоположных порядках: очередь отдаёт то что пришло первым, стек — то что пришло последним. Чтобы получить FIFO из двух LIFO, делаем так:

- stack_in — сюда складываем новые элементы
- stack_out — отсюда забираем


Когда нужно достать элемент, а stack_out пустой — перекидываем всё из stack_in в stack_out. При перекидывании порядок переворачивается, и наверху stack_out оказывается самый старый элемент. Значит достаём мы его первым — как и положено в очереди.

Если stack_out не пустой, ничего перекидывать не надо, просто pop.

## сложности

| Операция | Сложность |
|----------|-----------|
| dobavit | O(1) |
| dostat | амортизированно O(1), в худшем O(n) |
| front | то же самое |
| soderzhit | O(n) |

Амортизированно O(1) потому что каждый элемент перекидывается из in в out ровно один раз за всё время.

## Вариативная часть

soderzhit(x) просто проходит по обоим стекам и сравнивает. Если нашёл — True, иначе False. Порядок обхода не важен, потому что нам нужно только наличие.

## Граничные случаи

- dostat/front на пустой очереди — пишет "Очередь пуста" и возвращает None.
- soderzhit на пустой очереди — False.
- pokazat на пустой очереди — пустой список.
