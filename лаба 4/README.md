# Лаба 4. Подсчёт слов в тексте

## Задание

Программа анализирует текст и считает сколько раз встречается каждое слово.

Обязательная часть: прочитать строку, разбить на слова, посчитать повторы, вывести в формате слово -> количество.

Вариативная часть (6): вывести результат отсортированным по алфавиту.

## как рабртает

1. Строка разбивается на слова через split(). Если пробелов несколько подряд, split() сам разберётся, это его стандартное поведение.
2. Каждое слово кладём в словарь freq. Если слово уже есть — увеличиваем счётчик, если нет — ставим 1. Такой приём.
3. Для сортировки по алфавиту беру freq.keys(), пропускаю через sorted() и вывожу в этом порядке.

## Почему словарь

Для подсчёта частот словарь это самый очевидный вариант. Ключ — слово, значение — сколько раз встретилось. Вставка и поиск по ключу в среднем O(1), полный проход по тексту O(n). Если бы делал через два списка (слова и счётчики) было бы дольше и неудобнее.

## Граничные случаи

- пустая строка — словарь пустой, ничего не выводится.
- слова через несколько пробелов — split() обрабатывает.
- регистр не учитываю, это отдельная вариативная часть, мне не досталась.

## Пример

Ввёл "cat dog cat bird dog cat", получилось cat -> 3, dog -> 2, bird -> 1. По алфавиту: bird, cat, dog.
